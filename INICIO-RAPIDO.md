# ⚡ INÍCIO RÁPIDO - 2 MINUTOS

## 🚀 Passo 1: Instalar (30 segundos)

Abra o terminal/prompt nesta pasta e execute:

```bash
npm install
```

## ▶️ Passo 2: Executar (10 segundos)

```bash
npm start
```

**Pronto! A aplicação já está rodando!** 🎉

---

## 🎯 Teste Rápido (1 minuto)

### Adicione sua primeira tarefa:

1. Na aba "📋 Tarefas"
2. Digite no campo grande:
   ```
   Pedro hoje - Testar o Segundo Cérebro [alta]
   ```
3. Clique em "⚡ Processar Comandos"
4. ✅ Sua tarefa apareceu!

### Adicione mais tarefas de uma vez:

```
Walter hoje - Revisar código do projeto [média]
Paulo amanhã - Fazer deploy em produção [alta]
Pedro 15/02 - Reunião com cliente @Monnaie
```

**Clique em processar → 4 tarefas criadas!** 🎊

## 💡 Comandos Úteis

**Datas:**
- `hoje` - Data de hoje
- `amanhã` - Data de amanhã
- `15/02` - Dia específico

**Prioridades:**
- `[alta]` - 🔴 Urgente
- `[média]` - 🟡 Importante
- (nada) - 🔵 Normal

**Projetos:**
- `@Monnaie` - Associa ao projeto

**Tags:**
- `#urgent` - Adiciona tag

**Para todos:**
- `todos hoje - Reunião` - Cria para todos
