**Dicas para usar este arquivo:**

1. Salve este arquivo como `.md` ou `.txt`
2. Na aplicação, clique em "📥 Importar Checklist"
3. Selecione este arquivo
4. Todas as tarefas serão automaticamente importadas
5. Tarefas com `[x]` já vêm marcadas como concluídas
6. Prioridades são detectadas automaticamente: `[alta]`, `[média]`, `[normal]`
7. Prazos são extraídos automaticamente: `(prazo: DD/MM)`

**Formato suportado:**

```markdown
## NOME_DA_PESSOA - Descrição opcional (DATA opcional)
- [ ] Descrição da tarefa (prazo: DD/MM) [prioridade]
- [x] Tarefa concluída
```
