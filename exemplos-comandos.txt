═══════════════════════════════════════════════════════════════════════════════
💡 DICAS DE USO
═══════════════════════════════════════════════════════════════════════════════

1. MÚLTIPLAS TAREFAS: Cole várias linhas de uma vez para criar múltiplas tarefas

2. PRIORIDADES:
   - [alta] ou [high] = 🔴 Prioridade Alta
   - [média] ou [media] ou [medium] = 🟡 Prioridade Média
   - Sem especificar = 🔵 Prioridade Normal

3. DATAS:
   - "hoje" ou "today" = Data de hoje
   - "amanhã" ou "amanha" ou "tomorrow" = Data de amanhã
   - "DD/MM" = Data específica (ano atual)
   - "DD/MM/YYYY" = Data completa

4. PROJETOS:
   - Use @NomeDoProjeto para associar a um projeto
   - O nome pode ser parcial (ex: @Monn para Monnaie)

5. TAGS:
   - Use #tag para adicionar tags
   - Pode adicionar múltiplas tags (#tag1 #tag2 #tag3)

6. PESSOA "TODOS":
   - Use "todos" ou "all" para criar a mesma tarefa para todas as pessoas
